# Livewire Issues

Laravel project to showcase Livewire issues.

## Setup

The whole project runs on Docker with no local dependencies required (PHP, Composer, Node, etc.).

This project uses [just](https://just.systems/man/en) as a task runner.
See the [`justfile`](./justfile) for all available tasks.

1. Copy `.env.example` to `.env`.
2. Run `just setup`.
3. Visit `http://localhost:8000`.
